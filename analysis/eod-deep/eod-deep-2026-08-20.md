`14:40:02 bold — "The read operation timed out"`. One tick lost, no position at risk, no alert raised. A single timeout is not a fire; a **pattern** of them would be. Worth a counter rather than an investigation.

It never reads `automation/state/trendlines.json` — that file (count: 0, manual 0, auto 0) is a separate shadow artifact with no consumers. **The trigger is real; the file is unrelated.**
